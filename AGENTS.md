# Continuidad del proyecto

Antes de trabajar, lee `docs/CONTEXTO_MAESTRO.md` solo hasta `FIN DEL CONTEXTO VIGENTE`. Contiene estado, decisiones, pruebas, pendientes y protocolo de actualización para cualquier agente.

Comprueba rama, HEAD, cambios locales y PR actuales: el documento es una fotografía fechada, no sustituye Git ni las instrucciones del usuario. Consulta el anexo histórico solo cuando sea relevante; no cargues todo el archivo por defecto.

Al finalizar un trabajo, actualiza el estado y la bitácora en ese mismo documento con referencias de código/pruebas y pendientes reales. No mantengas listas vigentes paralelas en los documentos históricos. Conserva cambios ajenos, secretos fuera del repositorio y la distinción entre tests, merge, despliegue y aceptación del cliente.
